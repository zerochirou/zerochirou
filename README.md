### ◈ Portfolio Codebase & Architecture

This repository (`zerochirou/zerochirou`) serves a dual purpose:
1. **GitHub Special Profile**: The root documentation rendering on GitHub public profiles.
2. **Personal Portfolio Source**: The interactive portfolio engine powering [zerochirou.com](https://zerochirou.com).

#### Core Stack
- **Framework**: [Next.js 16.3.6](https://nextjs.org/) (App Router) + [React 19.2.8](https://react.dev/) + [TypeScript 5](https://www.typescriptlang.org/)
- **Package Manager**: Strictly enforced `pnpm@12.6.0`
- **Design System**: [Tailwind CSS v4](https://tailwindcss.com/) with CSS-first `@theme inline` & OKLCH color tokens
- **Component Primitives**: [shadcn/ui](https://ui.shadcn.com/) (`base-luma` style) built exclusively on [`@base-ui/react`](https://base-ui.com/) (no Radix UI)
- **Animation & Shaders**: Motion v12 (`motion/react`), GSAP 3, Three.js (`@react-three/fiber`), OGL minimal WebGL
- **Testing**: [Vitest](https://vitest.dev/) (`vitest`, `@testing-library/react`, `jsdom`)

#### Local Development

```bash
# Clone the repository
git clone https://github.com/zerochirou/zerochirou.git
cd zerochirou

# Install dependencies (strictly use pnpm)
pnpm install

# Start development server on http://localhost:3000
pnpm dev

# Run unit tests
pnpm test

# Run TypeScript typechecks & ESLint
pnpm typecheck
pnpm lint

# Build for production
pnpm build
```

#### Development & Design Conventions
All contributions, refactors, and AI coding agents must strictly adhere to the internal engineering specifications:
- [`AGENTS.md`](AGENTS.md) — Architectural guidelines, strict `snake_case` naming, dynamic WebGL loading, and zero-breakage rules.
- [`UIUX.md`](UIUX.md) — UI/UX design tokens, Base UI `render` prop patterns, sticky-scroll preservation, and motion timing curves.
