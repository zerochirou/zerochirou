# Desnet

Desnet is a peer-to-peer (P2P) network architecture that operates without central servers. Communication and protocol execution run directly on the custom desnet v1 engine.

## Architecture

* **Core Engine (C++):** Executes the desnet v1 protocol and manages direct node-to-node communication.
* **Tooling (Python):** Handles automated testing, network simulation, and protocol scripts.
