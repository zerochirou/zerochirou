# Devinion

Devinion bridges the gap between hardware engineering and software deployment. It serves as a comprehensive platform that simplifies the lifecycle of developing, deploying, and controlling complex hardware systems across distributed environments.

## System Design

Built for reliability and low-latency communication, Devinion's core control plane is written in Rust, utilizing gRPC for seamless communication with edge devices. The system is containerized via Docker for predictable deployments, while the user interface—built on Next.js—provides a unified dashboard for monitoring hardware telemetry and orchestrating over-the-air (OTA) updates.
